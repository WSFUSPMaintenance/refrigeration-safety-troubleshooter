# Refrigeration Safety Troubleshooter

Static GitHub Pages app for Wayne Farms Union Springs refrigeration safety control panel troubleshooting.

## Files

- `index.html`: main app shell
- `styles.css`: mobile friendly styling
- `app.js`: troubleshooting engine
- `data/devices.json`: device database
- `data/trees.json`: decision trees

## Deploy on GitHub Pages

1. Upload files to a GitHub repository.
2. Go to Settings → Pages.
3. Select branch and root folder.
4. Open the GitHub Pages URL.

## Current v0.1 Features

- Symptom selection
- Step-by-step troubleshooting
- Device lookup
- JSON-driven decision tree
